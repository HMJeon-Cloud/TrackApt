## 배포가 안 올라갈 때 (v9.95 메모)
- vercel.json 의 ignoreCommand 가 "이 파일들이 바뀐 커밋만 배포" 규칙이다. 목록: index.html · cards.js · style.css · api · vercel.json · .vercelignore · sw.js · manifest.webmanifest · data/manual (v9.95 에 cards.js·style.css·data/manual 추가).
- 같은 파일을 다시 올리면 GitHub 는 '바뀐 것 없음'으로 빈 커밋을 만들고, 빈 커밋은 위 규칙에 걸려 배포가 건너뛰어진다(Canceled, 오류 아님). 화면 배지가 안 바뀌면 Vercel › Deployments 에서 그 커밋의 상태를 먼저 본다.
- 강제로 올리려면 Deployments › ⋯ › Create Deployment 에 '실제로 파일이 바뀐 커밋' 주소를 넣는다(빈 커밋을 넣으면 또 건너뛴다). 대시보드의 Redeploy 는 그 항목의 옛 커밋을 다시 배포하는 것이라 새 파일이 올라가지 않는다.
- 새 커밋이 Deployments 목록에 아예 안 생기면 GitHub › Settings › Webhooks 의 Vercel 항목 Recent Deliveries 를 보고, 계속 실패하면 Vercel › Settings › Git 에서 Disconnect → Connect.
